Captions go in this folder.

Name each file like this:

  <video-id>.<lang>.vtt

Examples:

  first-video.en.vtt
  first-video.es.vtt
  my-song.de.srt

<video-id> is the "id" from videos.json. If the video has no "id", use the
file name of the video without its extension.

<lang> is a language code such as en, es, de, fr, pt or ja.

Use .vtt (WebVTT) when you can. .srt files also work.

OurTube finds these files automatically. You do not need to add them to
videos.json.
